# 摩登上海：漫画的Art Deco装饰语法

> CSSCI学术论文 | 目标：《装饰》（清华大学主办）「史论空间」栏目
> Modern Shanghai: The Art Deco Ornamental Grammar of Manhua

## 核心论点

上海漫画（1928-1937）中存在一套系统性的Art Deco装饰语法（线条→几何→色彩→文字四维框架）。它并非西方装饰艺术的被动输入，而是一种主动的**"翻译的现代性"**——借用全球Art Deco的形式框架，注入中国本土视觉基因（书法性线条、民间色谱、留白构图），形成了一条非西方的现代主义路径。

## 搭建流程

本论文使用 **PaperSpine** 论文写作技能套件全流程搭建：

1. **Intake** — 信息采集（目标期刊/字数/档位/格式）
2. **三代理并行研究** — 《装饰》期刊研究 + 范例论文学习 + SOTA差距分析
3. **引用银行** — 80条候选引用（38✅已验证+42⚠️待核实）
4. **动机确认** — 用户从3个选项中选择"翻译的现代性"
5. **章节蓝图 + 写作理由矩阵** — 22行逐段执行计划
6. **全文搭建** — 6章9,000汉字 + 10幅插图 + 2张自建表
7. **Heavy Humanize** — 54处去AI修改，覆盖知网D1-D5全部检测维度
8. **Word输出** — 可投稿的 .docx 格式
